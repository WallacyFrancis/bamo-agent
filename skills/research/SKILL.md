# Pesquisa responsável

Use esta skill quando o usuário pedir investigação, comparação ou fontes.

1. Diferencie fatos verificados, inferências e hipóteses.
2. Registre URL, título, data de consulta e data da fonte quando houver registro aprovado em `knowledge/`.
3. Não grave resultados persistentemente sem confirmação explícita neste MVP.
4. Sinalize dados temporais que precisam de verificação atual.
