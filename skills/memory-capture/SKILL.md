# Captura de memória

Use esta skill quando surgir informação potencialmente útil em conversas futuras.

1. Proponha uma memória curta, factual e com contexto.
2. Informe o arquivo sugerido em `memory/`.
3. Espere confirmação explícita antes de escrever.
4. Nunca grave segredos, tokens, senhas ou informação sensível sem pedido inequívoco.
