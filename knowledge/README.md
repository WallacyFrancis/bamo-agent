# Artefatos de conhecimento

Esta pasta receberá pesquisas, resumos e registros aprovados pelo usuário. Cada artefato deve informar data, fontes, escopo e nível de confiança.

## OKF (Organized Knowledge File)

OKF é o tipo de artefato de conhecimento aprovado neste projeto: um arquivo Markdown estruturado com campos fixos, gravado apenas após confirmação explícita do usuário (ver skill `research`). Campos obrigatórios:

- **Título**
- **Data do registro**
- **Fontes** (URL/título/autor quando houver)
- **Data de consulta** e, quando aplicável, **data da fonte**
- **Escopo** (o que o artefato cobre e o que não cobre)
- **Nível de confiança** (fato verificado, inferência ou hipótese)
- **Resumo**

O formato detalhado de nomeação de arquivo e automações de geração ficam para um PRD específico; esta definição cobre apenas a estrutura mínima de conteúdo.
